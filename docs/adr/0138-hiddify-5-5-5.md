# ADR 0138: Use Hiddify 5.5.5 for managed installation

## Status

Accepted

## Context

The Windows installer still downloaded Hiddify 4.1.1. Linux tried the mutable
`releases/latest` AppImage before falling back to 4.1.1, so the platforms could
install different versions.

## Decision

- Pin managed Hiddify downloads and manual installation guides to the official
  [5.5.5 release](https://github.com/hiddify/hiddify-app/releases/tag/v5.5.5).
- Linux downloads its versioned x64 AppImage directly. Windows retains the
  versioned x64 portable ZIP followed by the setup executable fallback.
- Preserve discovery of existing installations and their settings. This change
  selects the version for new managed installations; it does not replace an
  existing external client automatically.

## Validation

A cross-platform unit test checks the exact Linux and Windows asset URLs and
that the manual guide uses the same download as automatic installation.
